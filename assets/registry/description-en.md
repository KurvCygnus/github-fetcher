GitHub Fetcher is a read-only MCP server for AI coding agents that need reliable GitHub context on unstable networks. It reuses your existing git credential, reads file metadata through the GitHub contents API, fetches the raw body through your proxy when GitHub omits it, and caches responses with ETag revalidation. It exposes 34 tools for repositories, users, files, commits, issues, pull requests, releases, languages, contributors, repository activity and diagnostics, Actions, and search, including a read-only REST escape hatch. One command writes the client configuration. No writes, no GraphQL, no second secret store.
