GitHub Fetcher is a read-only MCP server for AI coding agents that need reliable GitHub context on unstable networks. It reuses your existing git credential, routes raw file requests through your proxy, falls back to the GitHub contents API, and caches responses with ETag revalidation. It exposes 22 tools for repositories, files, commits, issues, pull requests, releases, Actions, and search, including a read-only REST escape hatch. One command writes the client configuration. No writes, no GraphQL, no second secret store.
